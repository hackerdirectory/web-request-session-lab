    02 / Session lifecycle

    Cookie ve server store

    Cookie değeri bu panelde gösterilmez. DevTools Application/Cookies’te kendi yerel cookie’nizi gözleyin; screenshot/export’a identifier’ı taşımayın.

    Clock sabit 2030 başlangıcından yalnız düğmeyle ilerler. Server TTL: 300 demo saniyesi. Cookie Max-Age: 900 gerçek saniye. Amaç iki farklı lifetime’ı ayırmaktır; bu bir production session tasarımı değildir.

    Server state yükleniyor.
    Sanitized session store / lifecycle ledger
